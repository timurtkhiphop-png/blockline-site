# Деплой Contact Form на Timeweb

Сайт работает как статический экспорт (SSG), но для обработки форм мы используем PHP-скрипт, который загружается вместе со статикой.

## 1. Сборка проекта
Выполните production build:
```bash
npm run typecheck
npm run build:full
```
Убедитесь, что после сборки файл существует:
`out/api/lead.php`

## 2. Развёртывание файлов сайта
Загрузите всё содержимое папки `out` в публичную директорию вашего сайта на хостинге Timeweb (обычно это папка `public_html`, но точное название `document root` посмотрите в панели управления хостингом в разделе сайтов).

## 3. Настройка секретов (Вне публичной папки!)
Чтобы Telegram-бот работал и форма была защищена от спама, необходимо создать приватный файл конфигурации.
Он **обязательно** должен находиться на один уровень выше публичной папки `document root`, чтобы к нему нельзя было получить доступ через браузер.

1. Зайдите в файловый менеджер Timeweb.
2. Перейдите в папку, где находится ваша публичная папка (например, `public_html`), но не заходите в неё саму.
3. Создайте папку `private` (если её нет). Убедитесь, что у скрипта есть права на чтение из этой папки.
4. Внутри папки `private` создайте файл `820lab-lead-config.php`.
5. Вставьте в него следующий код:

```php
<?php

return [
    "telegram_bot_token" => "ВАШ_ТОКЕН_БОТА_ОТ_BOTFATHER",
    "telegram_chat_id" => "ВАШ_CHAT_ID",
    "rate_limit_secret" => "СЛУЧАЙНЫЙ_ДЛИННЫЙ_НАБОР_СИМВОЛОВ",
];
```

**Внимание:** Не загружайте этот файл конфигурации в публичную папку! `rate_limit_secret` необходим для хеширования IP-адресов пользователей, чтобы защитить форму от автоматических отправок. Данные rate limit хранятся во временной директории сервера (`sys_get_temp_dir()`), поэтому у PHP должны быть базовые права на запись временных файлов (обычно они есть по умолчанию).

## 4. Как получить Telegram Chat ID
1. Найдите бота **@userinfobot** в Telegram.
2. Напишите ему `/start`.
3. Бот вернёт ваш `Id` (например, `123456789`). Это и есть ваш `telegram_chat_id`.

## 5. Проверка PHP
- Убедитесь, что для сайта в панели Timeweb выбрана версия PHP не ниже 7.4 (рекомендуется 8.x).
- Проверьте доступность скрипта через браузер: перейдите по адресу `https://ваш-сайт/api/lead.php`.
- При правильной настройке GET-запрос должен вернуть ошибку (так как разрешен только POST-запрос) и ответ: `{"ok":false,"error":"method_not_allowed"}`.
- Если скрипт вместо выполнения скачивается или показывается как текст, значит на хостинге не включена поддержка PHP для статических файлов.
- При временно неверном конфиге или пустых токенах отправка формы с сайта будет выдавать ошибку 503 Service Unavailable.
- При частой отправке заявок (более 3 раз за 10 минут) сервер вернёт 429 Too Many Requests.

## 6. Тестирование
Поскольку локальный сервер Next.js (`npm run dev`) не исполняет PHP-файлы, реальную отправку необходимо тестировать **только на самом хостинге Timeweb**.

1. Откройте сайт на хостинге и заполните форму (ContactSection).
2. Нажмите «Отправить задачу».
3. Убедитесь, что форма показала успешное сообщение.
4. Проверьте ваш Telegram — должно прийти сообщение от бота.
5. Для теста Rate Limit попробуйте отправить форму 4 раза подряд (обновляя страницу). На 4-й раз форма должна выдать ошибку «Попробуйте немного позже...» и вернуть статус 429 в Network tab.

## 7. Rollback (Откат изменений)
Если после обновления выявилась критическая ошибка:
1. Загрузите в `document root` на хостинге содержимое `out` из предыдущей стабильной сборки.
2. Если предыдущей локальной сборки нет, выполните локально `git checkout <hash_предыдущего_коммита>`, затем `npm run build:full` и загрузите новый `out`.
3. Ошибки PHP можно откатить, просто заменив файл `public_html/api/lead.php` старой версией.
